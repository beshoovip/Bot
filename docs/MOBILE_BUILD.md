# بناء APK من الجوال فقط (MOBILE_BUILD)

> **حالة صريحة:** سير العمل `android-apk.yml` مكتوب لكنه **لم يُشغَّل ولم يُتحقَّق منه** في بيئة التطوير (لا يوجد فيها وصول إلى npm/Gradle/GitHub).
> لا يوجد APK جاهز ولا رابط مباشر حتى تشغّل البناء بنفسك وينجح. أول تشغيل قد يكشف أخطاء تحتاج إصلاحًا — أرسل لي نص الخطأ.

## ما تحتاجه
- حساب GitHub (مجاني). تطبيق GitHub أو المتصفح على الجوال يكفيان.
- خادم اللعبة منشور على الإنترنت (انظر `DEPLOYMENT.md`) — أو تدخل عنوانه داخل التطبيق لاحقًا.

## الخطوات
1. **أنشئ مستودعًا** على GitHub وارفع إليه ملفات المشروع كلها (من المتصفح: Add file ← Upload files، أو ارفع الملف المضغوط عبر Codespaces). تأكد أن مجلد `.github/workflows` رُفع.
2. **ولّد lockfiles (مرة واحدة):** تبويب **Actions** ← **Generate lockfiles** ← **Run workflow**. سيودع `package-lock.json` للخادم والعميل. (بدونها يعمل `npm install` لكن بإصدارات مثبتة في `package.json` فقط للاعتماديات المباشرة.)
3. **شغّل بناء APK:** Actions ← **Build Android APK** ← **Run workflow**، واكتب في الحقل عنوان الخادم مثل `https://my-game.onrender.com` (أو اتركه فارغًا وأدخله داخل التطبيق).
   - يمكنك بدلًا من ذلك ضبط متغير مستودع `SERVER_URL` (Settings ← Secrets and variables ← Actions ← Variables).
4. انتظر 10–20 دقيقة. عند النجاح افتح التشغيل ← قسم **Artifacts** ← نزّل `caravan-road-debug-apk`، وفكّ الضغط إن لزم (GitHub يضغط الملف) لتحصل على `caravan-road-debug.apk`.
5. **التثبيت:** افتح الملف على الجوال، واسمح بـ "التثبيت من مصادر غير معروفة" لمتصفحك/مدير الملفات عند الطلب.
6. **رابط مباشر (اختياري):** أنشئ وسمًا (Release/tag) يبدأ بـ `v` مثل `v0.1.0` — يرفق السير APK بصفحة Release فتحصل على رابط تنزيل مباشر.

## ملاحظات
- النتيجة APK **debug** (موقَّع بمفتاح تصحيح): يصلح للتجربة والتوزيع الخاص، لا للنشر في Google Play.
- التطبيق يُجبَر على الوضع الأفقي (`sensorLandscape`) عبر تعديل Manifest في السير.
- عنوان الخادم يُحفظ في التطبيق ويمكن تغييره من شاشة الدخول (قسم "الخادم").
- Capacitor 8 يتطلب JDK 21 وNode 22 (مضبوطان في السير).
- **إصدار موقَّع للنشر:** أنشئ keystore، خزّنه Base64 في GitHub Secrets مع كلمات المرور، وأضف خطوة توقيع (`./gradlew assembleRelease` مع `signingConfigs`). لم يُنفَّذ هنا؛ لا تضع المفتاح في المستودع أبدًا (`.gitignore` يمنع `*.keystore`/`*.jks`).
- إن فشل البناء بسبب إصدار حزمة غير موجود: الإصدارات المثبتة في `client/package.json` و`server/package.json` اختيرت من بحث نظري ولم تُثبَّت فعليًا في بيئة التطوير؛ عدّل الرقم المذكور في رسالة الخطأ إلى أقرب إصدار موجود.
